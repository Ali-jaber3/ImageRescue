# تشغيل تحديث ImageRescue

1. أغلق النسخة القديمة من البرنامج.
2. فك ضغط الحزمة في مجلد مؤقت، ثم انسخ محتوياتها إلى مستودع ImageRescue الحالي.
3. وافق على استبدال الملفات. احتفظ بمجلد .git الحالي؛ الحزمة لا تحتوي عليه.
4. افتح Terminal من داخل المستودع، وشغّل:

```powershell
dotnet build .\src\ImageRescue.App\ImageRescue.App.csproj -c Release
Start-Process '.\src\ImageRescue.App\bin\Release\net10.0-windows\ImageRescue.App.exe' -Verb RunAs
```

وافق على نافذة صلاحية المسؤول. هذا الإصدار يستهدف ويندوز x64.

## اختبار USB أو SD

- استخدم فلاشًا تجريبيًا، وشغّل البرنامج من القرص الداخلي.
- وصّل الفلاش واضغط «تحديث الأجهزة» ثم اختر حرفه واسمه وسعته.
- اختر مجلد حفظ على القرص الداخلي. يجب أن يكون قرصًا فعليًا مختلفًا عن الفلاش.
- اضغط «فحص واسترجاع». ستُحفظ الصور مباشرة داخل مجلد جديد مميز لكل عملية.
- افتح مجلد النتائج وافتح الصور يدويًا؛ راجع scan-session.json للعدد والبصمات.
- جرّب الإلغاء؛ يجب أن تبقى الصور المكتملة، ويُسجل الإلغاء في التقرير.
- جرّب تصغير النافذة والتمرير خارج الجدول وداخله.
- جرّب اللغتين والمظاهر الثلاثة أثناء الفحص.
- جرّب اختيار وجهة على الفلاش نفسه: يجب رفض العملية قبل إنشاء مجلد النتائج.

الفحص يشمل القسم المختار فقط، ويجد الصور الموجودة والمحذوفة معًا. لا يضمن
استرجاع الصور المجزأة أو المكتوب فوقها. الحد للصورة 64 MiB و40 ميجابكسل.
اختبارات المحرك نجحت والبناء نجح، لكن USB الفعلي والواجهة يحتاجان تجربة ويندوز.

## تحديث GitHub بعد الاختبار

```powershell
git status
git add src tests tools docs .github README.md .gitignore
git commit -m "Add USB and SD photo recovery, cancellation and scrollable UI"
git push
```

راجع git status قبل الإضافة. لا ترفع صور أقراص شخصية أو صورًا مسترجعة.
سيظهر فحص البناء والاختبارات في تبويب Actions بعد الرفع.

## تحديث 0.2

فك الحزمة خارج المستودع وأغلق البرنامج. استخدم Install-Update.ps1 مع RepoPath
لمسار المستودع الحالي. ينقل src القديم إلى نسخة احتياطية خارج المستودع ثم ينسخ
مجلد src نظيفًا، ويحافظ على .git. لا تخلط نسخ الكود القديمة والجديدة.

- مسار الحفظ يظهر كاملًا في مربع مستقل، ويمكن نسخه.
- السريع يفحص بدايات قطاعات 512 بايت؛ العميق يفحص كل بايت. كلاهما يقرأ المصدر
  كاملًا، والسريع قد يفوّت صورًا. العميق لا يعيد تجميع الصور المجزأة.
- زر إيقاف مؤقت يتحول إلى متابعة. الإلغاء ينهي الفحص مع إبقاء الصور المكتملة.
- اختر بداية الاسم قبل الفحص. بعد انتهائه حدد صورة ثم غيّر اسمها؛ يُعدّل الملف
  الفعلي والتقرير، ولا تتغير بايتات الصورة. لا تُستعاد الأسماء الأصلية بهذه الطريقة.
- اختر الفرز بالاسم أو الحجم أو النوع، ثم تصاعدي أو تنازلي. الحجم يُفرز رقميًا.
- يعرض الجدول الحجم بالبايت وMiB والأبعاد. لا يستخدم البرنامج ضغط الصور.
  الصورة الصغيرة قد تكون نسخة مصغرة موجودة أصلًا داخل ملف آخر؛ لا يمكن الجزم
  بسبب اختلاف حجم صورك دون مقارنة الأصل بالمسترجع.

للاختبار: جرّب وضعَي الفحص على نفس المصدر، والإيقاف والمتابعة والإلغاء أثناء
التوقف. جرّب اسمًا جديدًا لصورة وافتحها، وتحقق من الأبعاد والمسار والفرز. نجحت
45 عملية تحقق آلية والبناء دون أخطاء؛ واجهة ويندوز وUSB يحتاجان تجربة محلية.
